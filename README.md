# N.O.V.A

Agent de vie personnel, en appli web installable sur iPhone (PWA).

- 5 espaces : Accueil (noyau), Chat, Mémoire, Labo (évolution mesurée et réversible), Outils.
- Toutes les données restent dans le téléphone (IndexedDB). Ce dépôt ne contient que le code, aucune donnée.
- Marche sans Internet ; le cerveau en ligne (Gemini, Groq ou OpenRouter, clés gratuites gardées dans le téléphone) n'est utilisé qu'avec l'autorisation de l'utilisateur.
- Rappels par ntfy.

Installation : ouvrir la page dans Safari, Partager, « Sur l'écran d'accueil ».

Polices : Inter, Space Grotesk, JetBrains Mono (licence SIL OFL, voir `fonts/`). jsPDF (licence MIT).
